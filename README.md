## Installation

1. Clone the repository: `git clone https://github.com/irenascent/HiveNexus.git`
2. `cd HiveNexus`
3. Install in editable mode: `pip install -e .`

## Configuration

HiveNexus is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
